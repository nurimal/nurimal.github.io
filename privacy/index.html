누리말

개인정보 처리방침

시행일 2026년 10월 23일

누리말은 화면 자막과 영상 음성을 기기 안에서 번역하는 앱입니다. 회원가입이 없고 번역을 위해 이름이나 연락처를 요구하지 않습니다. 최근 원문과 번역문은 기기의 실행 로그에 남으며, 사용자가 의견과 함께 보내기로 선택하면 개발자에게 전달될 수 있습니다. 앱 화면 아래에는 Google AdMob 광고를 표시하며, 광고를 위해 Google에 전달되는 정보는 아래 '광고' 항목에 적었습니다.

1. 기기 안에서만 처리하는 정보

  • 화면 이미지: 자막 번역 중에는 지정한 인식 범위의 글자만 인식하며, 이미지는 저장하거나 서버로 보내지 않습니다.
  • 영상 음성: 음성 번역 중에는 다른 앱이 재생하는 소리를 텍스트로 바꿀 뿐 마이크로 주변 소리를 녹음하지 않으며, 소리는 저장하거나 서버로 보내지 않습니다.
  • 원문과 번역문: 누리말 창에 표시하는 동안 기기 메모리에 있고, 문제를 찾는 데 쓰는 실행 로그 파일에 최근 원문과 번역문이 남았다가 오래된 것부터 지워집니다. 번역을 위해 서버로 보내지 않으며, 의견 보내기에서 사용자가 첨부를 선택한 경우는 아래 안내와 같습니다.
  • 자막 언어 확인: 읽은 자막이 선택한 원문 언어에 맞는지 앱에 들어 있는 Google ML Kit 언어 식별 모델로 기기 안에서 확인합니다. 언어 확인을 위한 자막 원문은 외부 서버에 전송하지 않습니다. 진단 지표의 처리는 아래 인터넷 사용 안내에 적었습니다.

2. 기기에 저장하는 정보

  • 설정: 언어, 누리말 창 모양과 위치, 인식 범위를 저장합니다.
  • 글꼴과 AI 모델: 직접 가져온 글꼴 파일과 다운로드한 AI 모델 파일(번역, 음성 인식, 선택 사항인 화자 구분)을 저장합니다. 개발 테스트 빌드에서 제공하는 PP-OCR 글자 인식을 이용하면 해당 모델과 글자 사전 파일도 앱 전용 공간에 저장합니다.
  • 사전: 사전 탭에서 직접 만들거나 파일에서 가져온 단어와 번역, 켜둔 공식 사전의 사본을 저장합니다. 사전을 파일로 저장하거나 다른 사람에게 보내는 일은 사용자가 직접 할 때만 일어납니다.
  • 진단 기록: 최근 번역의 실행 시간, 번역 횟수, 처리 속도, 메모리 사용량, GPU 종류, 오류 요약과 Android가 제공하는 앱 종료 기록을 이용합니다. 실행 로그에는 처리 단계와 시각, 오류 종류, 최근 원문과 번역문을 담습니다.
  • 실행 로그 파일: 앱 전용 공간에 구간당 최대 1MB(1,000,000바이트)인 파일을 최대 5개, 합계 최대 5MB 보관하며 용량이 차면 오래된 구간부터 지웁니다.
  • 첨부 사본: 의견 보내기를 준비할 때 실행 구간을 합쳐 diag.log 한 개를 만들며, 완성된 첨부 사본을 실행 로그와 별도로 최대 5개(각 최대 5MB) 보관합니다. 실행 구간과 완성 사본은 합계 최대 약 30MB이며, 새 사본을 만드는 중에는 최대 5MB의 임시 사본 또는 정리 전 새 완성본 하나가 추가로 있을 수 있습니다. 파일 삭제 실패 시에는 정리가 끝나지 않은 사본이 남을 수 있습니다.
  • 앱 전용 저장: 이 정보는 앱 전용 공간에 보관하고 기기 백업에는 포함하지 않습니다. 사용자가 의견 첨부를 선택하면 선택한 메일 앱이나 공유 앱에 완성된 사본의 읽기를 허용합니다.
  • 정책 사본: 이 앱 버전에 적용되는 개인정보 처리방침을 기기에 저장하며, 새 정책을 받으면 다음 실행부터 표시합니다.

3. 인터넷을 사용하는 경우

  • AI 모델 다운로드: 처음 사용할 때 Hugging Face(huggingface.co)에서 번역·음성 인식 모델을 받고, 설정에서 화자 구분을 켜면 화자 구분 모델도 받습니다. AI 모델 탭에서 다른 번역 모델의 받기를 누르면 해당 모델을 받습니다. 개발 테스트 빌드에서 제공하는 PP-OCR 글자 인식을 이용하면 Hugging Face의 PaddlePaddle 저장소에서 해당 모델과 글자 사전 파일을 받습니다. 다운로드 요청에 번역 내용이나 기기 식별자를 담지 않지만 IP 주소 등 일반 접속 정보는 Hugging Face와 다운로드를 처리하는 연결 서버에 전달될 수 있으며 해당 제공자의 개인정보 처리방침이 적용됩니다.
  • 글자 인식(Google ML Kit, Google Play 서비스): 글자 인식 모델은 앱에 들어 있지 않으며 기기의 Google Play 서비스가 처음 한 번 Google 서버에서 받아 둡니다. 화면 이미지와 인식 결과는 외부 서버에 전송하지 않지만, Google Play 서비스가 모델을 받거나 ML Kit이 성능과 사용량 지표를 Google에 보내고 업데이트를 확인할 때 Google 서버에 접속할 수 있으며, 이 과정에는 Google 개인정보처리방침이 적용됩니다.
  • 자막 언어 확인(Google ML Kit): 언어 식별 모델은 앱에 들어 있어 인터넷 없이 자막의 언어를 확인할 수 있습니다. 자막 원문은 외부 서버에 전송하지 않습니다. ML Kit은 진단과 사용량 분석을 위해 판별된 언어 종류, 기기 종류와 운영체제, 앱 버전, 설치별 식별자, 처리 시간, 입력·출력 크기와 오류 코드 등의 지표를 Google에 전송할 수 있으며 Google 개인정보처리방침이 적용됩니다.
  • 광고(Google AdMob): 앱 화면을 여는 동안 광고를 받기 위해 Google 서버에 접속합니다. 전달되는 정보와 선택 방법은 아래 '광고' 항목에 있습니다.
  • 정책 업데이트: 앱을 실행하면 누리말 홈페이지(nurimal.github.io)의 정책 파일을 확인하고 새 내용이 있으면 다운로드합니다. 번역 내용이나 기기 식별자를 보내지 않지만 IP 주소와 요청 시각 같은 일반 접속 정보는 호스팅 제공자인 GitHub에 전달될 수 있으며 GitHub의 개인정보 처리방침이 적용됩니다.
  • 공식 사전 갱신: 앱을 실행하면 하루 한 번 누리말 홈페이지(nurimal.github.io)의 공식 사전 목록을 확인하고, 사전 탭에서 켜둔 공식 사전에 새 판이 있으면 그 파일을 다운로드합니다. 정책 업데이트와 같은 방식으로 번역 내용이나 기기 식별자를 보내지 않으며, 일반 접속 정보는 GitHub에 전달될 수 있습니다.
  • AI 모델 목록 갱신: 앱을 실행하면 마지막 확인에서 24시간이 지났을 때 누리말 홈페이지(nurimal.github.io/models/list.json)의 목록을 확인합니다. 번역뿐 아니라 음성 인식·글자 인식·화자 구분 등 AI 모델 탭 전체 항목의 설명·출처·크레딧을 포함하는 목록이며, 목록 확인만으로 새 모델 파일을 자동 설치하지 않습니다. 받지 못하면 기기에 저장된 목록이나 앱 동봉 사본을 사용합니다. 번역 내용이나 기기 식별자를 보내지 않지만 IP 주소와 요청 시각 등 일반 접속 정보는 GitHub에 전달될 수 있습니다.
  • 외부 정책 링크: 앱의 관련 정책이나 웹에서 최신 정책 보기를 누르면 외부 브라우저로 Hugging Face·Google·GitHub 또는 누리말 홈페이지에 연결합니다. 이때 일반 접속 정보와 브라우저가 제공하는 정보의 처리는 해당 사이트·호스팅 제공자의 정책을 따릅니다. 번역 내용이나 실행 로그를 이 링크에 담아 보내지 않습니다.
  • 모델을 받은 뒤에는 인터넷 없이 번역합니다.

4. 의견·문제 보내기

  • 전송 선택: 적은 글은 사용자가 선택한 메일 앱으로 개발자 주소(nurimal.app@gmail.com)에 보낼 수 있고, 메일 앱이 없으면 다른 공유 앱을 선택할 수 있습니다. 누리말이 자동으로 개발자 서버에 전송하지 않으며 사용자가 외부 앱에서 전송을 결정합니다. 외부 앱에 넘긴 뒤의 임시 저장·동기화·전송에는 해당 앱과 서비스의 정책이 적용됩니다.
  • 첨부와 동의: ‘진단 정보와 실행 로그 함께 보내기’는 기본으로 켜져 있습니다. 앱 버전, 기기 모델명, Android 버전, GPU 종류, AI 실행 방식, 성능 수치, 최근 종료 원인 요약과 처리 단계·최근 원문·번역문이 담긴 diag.log 한 개가 포함됩니다. 이 안내와 첨부 선택을 확인하고 동의하는 경우에만 보내 주세요. 끄면 적은 글만 넘깁니다. 화면 이미지와 음성은 어느 경우에도 담지 않습니다.
  • 외부 앱의 사본: 첨부를 넘긴 메일 앱이나 공유 앱은 자체 사본을 만들거나 서버에 보관할 수 있습니다. 누리말의 설정 초기화·사본 만료·앱 삭제로 그 사본을 회수하거나 삭제할 수 없으며, 해당 앱이나 서비스에서 직접 관리해야 합니다.
  • 개발자에게 전달되는 정보: 메일로 보내면 보낸 사람의 이메일 주소와 사용자가 보낸 내용·선택한 진단 정보가 개발자에게 전달됩니다. 개발자는 이를 답장과 문제 확인에만 쓰고 다른 목적에 쓰거나 판매하지 않습니다. 받은 의견과 첨부의 삭제를 원하면 문의 이메일로 요청할 수 있습니다.

5. 권한과 사용 목적

  • 다른 앱 위에 표시: 누리말 창을 영상과 게임 위에 띄웁니다.
  • 화면 캡처: 원문 자막을 읽고 영상 소리를 받는 데 쓰며, 번역을 시작할 때 Android 동의 화면에서 허용하고 번역을 종료하면 함께 멈춥니다.
  • 오디오 녹음: Android에서 다른 앱의 소리를 받는 데 필요한 권한이며 마이크 녹음에는 사용하지 않습니다.
  • 알림: 번역 실행 중 상태와 모델 다운로드 진행 상황을 알립니다.
  • 인터넷: AI 모델 받기, 개인정보 처리방침·공식 사전·AI 모델 목록의 확인과 다운로드, 광고 표시에 사용합니다.
  • 광고 ID: Google 모바일 광고 SDK가 광고 제공과 측정에 쓰는 Android 광고 식별자를 읽습니다. 기기 설정에서 광고 ID를 삭제하면 식별자 대신 0으로 채운 값이 전달됩니다.

6. 정보 삭제

  • 설정 초기화: 저장된 설정과 인식 범위, 진단 기록, 실행 로그 구간과 앱 안의 완성·임시 첨부 사본을 삭제합니다. 번역 종료를 기다리지 못하거나 로그 삭제 완료를 확인하지 못하면 초기화가 실패할 수 있으므로 완료되지 않았다는 안내가 나오면 다시 시도해 주세요. 일부 삭제 뒤 실패할 수도 있으며, 실패 안내를 삭제 완료로 보지 마세요. 이후 앱을 사용하면 새 실행 로그가 쌓입니다.
  • 실행 로그 만료: 마지막 실행 구간 기록 뒤 14일이 지난 로그는 다음 앱 시작 시 정리합니다. 앱을 실행하지 않는 동안 정확히 14일째에 삭제되는 방식은 아닙니다.
  • 첨부 사본 만료: 완성된 첨부 사본은 생성 후 14일이 지났을 때 다음 앱 시작 또는 첨부 준비 시 정리하며, 첨부 준비 시 완성 사본 수가 5개를 넘으면 오래된 사본부터 지웁니다. 생성 중 남은 임시 사본은 다음 앱 시작 또는 첨부 준비 시 정리합니다. 저장 장치 오류 등으로 삭제가 실패하면 사본이 남을 수 있으므로 초기화를 다시 시도하거나 앱을 삭제할 수 있습니다.
  • 사전 탭에서 나만의 사전 항목과 가져온 사전을 삭제하고 공식 사전을 끌 수 있습니다.
  • AI 모델 탭에서 다운로드한 모델을 삭제할 수 있습니다.
  • 앱을 삭제하면 앱 전용 공간의 정보가 함께 지워집니다. 외부에 저장·전달한 사전·로그나 메일 앱·공유 앱·수신자의 사본은 함께 지워지지 않습니다.

7. 광고

  • 광고 표시: 홈·AI 모델·사전·설정 화면 아래에 Google AdMob 배너 광고를 표시합니다. 앱 안에서 누리말 종료를 눌러 2분 이상 이어진 번역을 끝내면 전체 화면 광고가 나올 수 있으며, 30분에 한 번을 넘지 않습니다. 다른 앱 위에 띄우는 누리말 창에는 광고를 넣지 않으며, 번역 중이거나 앱이 화면에서 내려가 있는 동안에는 새 광고를 요청하지 않고 표시 중인 광고도 내립니다.
  • Google에 전달되는 정보: 광고를 받아 표시하는 동안 Google 모바일 광고 SDK가 광고 ID와 앱 세트 ID 같은 기기 식별자, IP 주소(대략적인 위치를 추정하는 데 쓰일 수 있음), 광고 노출과 탭 같은 앱 안 상호작용, 앱 실행 시간과 멈춤 같은 진단 정보를 Google에 보냅니다. Google은 이 정보를 광고 제공과 측정, 분석, 부정 사용 방지에 쓰며 Google 개인정보처리방침이 적용됩니다.
  • 번역 내용과 광고: 화면 이미지, 영상 음성, 원문과 번역문, 실행 로그는 광고 SDK에 넘기지 않으며 광고를 위해 외부 서버에 전송하지 않습니다.
  • 맞춤 광고 선택: Android 설정의 Google 또는 개인정보 보호 메뉴에 있는 '광고'에서 광고 ID를 삭제하거나 재설정할 수 있습니다(기기마다 메뉴 이름이 다를 수 있습니다). 유럽 경제 지역(EEA)·영국 등 동의가 필요한 지역에서는 처음 광고를 표시하기 전에 동의 창이 나타나며, 설정의 '광고 개인정보 선택'에서 언제든 바꿀 수 있습니다.
  • 판매와 제3자 제공: 번역 내용과 실행 로그를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 위 광고 정보는 Google이 앱 안의 광고 SDK로 직접 수집하고 처리합니다.
  • 처리 방식이 바뀌면 이 안내를 먼저 고치고 앱 업데이트로 알립니다.
