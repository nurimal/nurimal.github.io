누리말

개인정보 처리방침

시행일 2026년 10월 15일

누리말은 화면 자막과 영상 음성을 기기 안에서 번역하는 앱으로, 회원가입이 없고 이름이나 연락처 같은 개인정보를 수집하지 않습니다.

1. 기기 안에서만 처리하는 정보

  • 화면 이미지: 자막 번역 중에는 지정한 인식 범위의 글자만 인식하며, 이미지는 저장하거나 서버로 보내지 않습니다.
  • 영상 음성: 음성 번역 중에는 다른 앱이 재생하는 소리를 텍스트로 바꿀 뿐 마이크로 주변 소리를 녹음하지 않으며, 소리는 저장하거나 서버로 보내지 않습니다.
  • 원문과 번역문: 누리말 창에 표시하는 동안 기기 메모리에 있고, 문제를 찾는 데 쓰는 실행 로그 파일에 최근 원문과 번역문이 남았다가 오래된 것부터 지워지며, 서버로 보내지 않습니다.

2. 기기에 저장하는 정보

  • 설정: 언어, 누리말 창 모양과 위치, 인식 범위를 저장합니다.
  • 글꼴과 AI 모델: 직접 가져온 글꼴 파일과 다운로드한 AI 모델 파일(번역, 음성 인식, 선택 사항인 화자 구분)을 저장합니다.
  • 사전: 사전 탭에서 직접 만들거나 파일에서 가져온 단어와 번역, 켜둔 공식 사전의 사본을 저장합니다. 사전을 파일로 저장하거나 다른 사람에게 보내는 일은 사용자가 직접 할 때만 일어납니다.
  • 진단 기록: 최근 번역의 실행 시간, 번역 횟수, 처리 속도, 메모리 사용량, GPU 종류, 오류 요약을 저장하고, 번역이 어느 단계에서 늦거나 빠졌는지 알 수 있도록 처리 단계와 시각, 오류 종류, 최근 원문과 번역문을 담은 실행 로그 파일을 앱 전용 공간에 최대 5MB까지 두며, 마지막 기록 뒤 14일이 지나면 앱이 스스로 지우고, Android가 제공하는 앱 종료 기록도 읽습니다.
  • 이 정보는 앱 전용 공간에 있어 다른 앱이 읽을 수 없고, 기기 백업에도 포함하지 않습니다.
  • 정책 사본: 이 앱 버전에 적용되는 개인정보 처리방침을 기기에 저장하며, 새 정책을 받으면 다음 실행부터 표시합니다.

3. 인터넷을 사용하는 경우

  • AI 모델 다운로드: 처음 한 번 Hugging Face(huggingface.co) 서버에서 번역 모델과 음성 인식 모델을 받고, 설정에서 화자 구분을 켜 두면 화자 구분 모델도 받습니다. 다운로드 요청에는 번역 내용이나 개인정보를 담지 않지만, IP 주소 같은 일반 접속 정보는 해당 서버에 전달될 수 있으며 이 정보에는 Hugging Face의 개인정보 처리방침이 적용됩니다.
  • 글자 인식(Google ML Kit, Google Play 서비스): 글자 인식 모델은 앱에 들어 있지 않으며 기기의 Google Play 서비스가 처음 한 번 Google 서버에서 받아 둡니다. 화면 이미지와 인식 결과는 외부 서버에 전송하지 않지만, Google Play 서비스가 모델을 받거나 ML Kit이 성능과 사용량 지표를 Google에 보내고 업데이트를 확인할 때 Google 서버에 접속할 수 있으며, 이 과정에는 Google 개인정보처리방침이 적용됩니다.
  • 정책 업데이트: 앱을 실행하면 누리말 홈페이지(nurimal.github.io)의 정책 파일을 확인하고 새 내용이 있으면 다운로드합니다. 번역 내용이나 기기 식별자를 보내지 않지만 IP 주소와 요청 시각 같은 일반 접속 정보는 호스팅 제공자인 GitHub에 전달될 수 있으며 GitHub의 개인정보 처리방침이 적용됩니다.
  • 공식 사전 갱신: 앱을 실행하면 하루 한 번 누리말 홈페이지(nurimal.github.io)의 공식 사전 목록을 확인하고, 사전 탭에서 켜둔 공식 사전에 새 판이 있으면 그 파일을 다운로드합니다. 정책 업데이트와 같은 방식으로 번역 내용이나 기기 식별자를 보내지 않으며, 일반 접속 정보는 GitHub에 전달될 수 있습니다.
  • 모델을 받은 뒤에는 인터넷 없이 번역합니다.

4. 의견·문제 보내기

  • 설정의 의견·문제 보내기에서 적은 글은 사용자의 메일 앱을 통해 개발자 주소(nurimal.app@gmail.com)로 보내며, 메일 앱에서 보내기를 누르기 전에는 어떤 정보도 외부 서버에 전송하지 않습니다.
  • ‘진단 정보와 실행 로그 함께 보내기’가 켜져 있으면(기본 켜짐) 앱 버전, 기기 모델명, Android 버전, GPU 종류, AI 실행 방식, 성능 수치, 최근 종료 원인 요약과 함께 처리 단계·최근 원문·번역문이 담긴 실행 로그 파일이 첨부되며, 끄면 적은 글만 보냅니다. 화면 이미지와 음성은 어느 경우에도 담지 않습니다.
  • 메일은 사용자의 메일 계정에서 보내므로 보낸 사람의 이메일 주소가 개발자에게 전달되며, 개발자는 이를 답장과 문제 확인에만 쓰고 다른 목적에 쓰거나 제3자에게 제공하지 않습니다.

5. 권한과 사용 목적

  • 다른 앱 위에 표시: 누리말 창을 영상과 게임 위에 띄웁니다.
  • 화면 캡처: 원문 자막을 읽고 영상 소리를 받는 데 쓰며, 번역을 시작할 때 Android 동의 화면에서 허용하고 번역을 종료하면 함께 멈춥니다.
  • 오디오 녹음: Android에서 다른 앱의 소리를 받는 데 필요한 권한이며 마이크 녹음에는 사용하지 않습니다.
  • 알림: 번역 실행 중 상태와 모델 다운로드 진행 상황을 알립니다.
  • 인터넷: AI 모델 다운로드, 개인정보 처리방침과 공식 사전의 확인·다운로드에 사용합니다.

6. 정보 삭제

  • 설정 초기화로 저장된 설정과 인식 범위, 진단 기록과 실행 로그 파일을 지울 수 있습니다.
  • 실행 로그 파일은 지우지 않아도 용량(5MB)이 차면 오래된 것부터 지워지고, 마지막 기록 뒤 14일이 지나면 앱이 스스로 모두 지웁니다.
  • 사전 탭에서 나만의 사전 항목과 가져온 사전을 삭제하고 공식 사전을 끌 수 있습니다.
  • AI 모델 탭에서 다운로드한 모델을 삭제할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 정보가 함께 지워집니다.

7. 광고와 제3자 제공

  • 현재 버전은 광고를 표시하지 않으며, 개인정보를 제3자에게 제공하거나 판매하지 않습니다.
  • 광고 도입 등 처리 방식이 바뀌면 이 안내를 먼저 고치고 앱 업데이트로 알립니다.
